## Random Dog Image Generator
A simple web application that fetches and displays a random dog image every time you click a button. This project demonstrates the use of Async/Await, the Axios library, and interacting with a Public API.

# Features
Fetches real-time data from the Dog CEO API.
Smooth asynchronous updates without refreshing the page.
Simple, clean UI with basic error handling. 

# Technologies Used
HTML5: Structure of the page.
JavaScript (ES6+): Logic and API handling.
Axios: A promise-based HTTP client for the browser.
